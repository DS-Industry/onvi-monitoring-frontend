# QA: раздел Analytics

Документация для тестировщиков и менеджеров продукта по мониторингу сети моек и станций.

## Маршруты

| Экран | URL | Компонент |
|---|---|---|
| Сеть станций | `/station/enrollments` | `PosOverviewNetwork` |

`/station` — родительский маршрут с навигацией; рабочие экраны находятся в дочерних маршрутах.

## Общие предусловия

1. Пользователь авторизован и выбрана организация.
2. У пользователя есть `read` или `manage` на subject `Pos`.
3. В организации есть хотя бы одна станция, устройство и данные за тестовый период.
4. Для изменения станции или месячного плана дополнительно нужны права `update` или `manage`.
5. Тарифная проверка: раздел доступен для `BASIC_AND_UP`; фактическая доступность зависит от feature flags и прав пользователя.
6. Для проверок дат подготовлены периоды с данными и без данных; даты передаются в API как ISO datetime.

## Бизнес-модель

- **POS / станция** — точка бизнеса с адресом, типом мойки, режимом работы, лимитами суммы заказа и привязкой к организации.
- **Депозит** — финансовая операция, загруженная с устройства; содержит сумму, дату операции, дату загрузки, валюту, счётчик и локальный идентификатор.
- **Программа** — режим/услуга мойки, агрегируемая по устройствам и типу операции `PAYMENT` или `CLEANING`.
- **План/факт** — месячный денежный план станции и фактическая выручка по каналам оплаты.
- **Устройство** — источник телеметрии и операций станции; подробности открываются по `deviceId`.

## Важные правила

- Без `countryId` сетевые экраны не выполняют основной запрос и показывают предложение выбрать страну.
- Изменение периода, фильтра, режима или размера страницы сбрасывает соответствующую пагинацию.
- На карточке Portal-станции вкладка Cleaning скрыта; для остальных типов она доступна.
- Конвертация валюты меняет отображение денежных значений, но не исходные данные API.
- Отсутствие данных — штатный результат и отображается как empty state; ошибка API отображается отдельным alert.
- Ввод месячного плана не может быть отрицательным; сохранение доступно только после изменения значения.
