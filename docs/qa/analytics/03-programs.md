# Программы и операции программных устройств

## 1. Сеть программ — `/station/programs`

### О странице

| Вопрос | Ответ |
|---|---|
| **Зачем** | Анализировать использование программ, количество запусков и время выполнения в сети или на выбранной станции. |
| **Что менеджерит** | Агрегаты программ по устройствам и тип операции: `PAYMENT` или `CLEANING`. |
| **Кто пользуется** | Операционный менеджер, руководитель сети и аналитик. |
| **Связи** | POS, устройства, программы, период и детальный журнал устройства. |
| **Правила** | `PAYMENT` — платные операции, `CLEANING` — очистка; смена типа операции сбрасывает страницу. |

### Тест-кейсы

#### ТК-PROG-01 — список и тип операции

**Предусловия:** есть данные программ, пользователь имеет `read`/`manage` на `Pos`.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `/station/programs` | Загружаются устройства и агрегаты программ |
| 2 | Выбрать `PAYMENT` | Запрос получает `turningType=PAYMENT`, показатели соответствуют платным мойкам |
| 3 | Выбрать `CLEANING` | Запрос получает `turningType=CLEANING`, показатели соответствуют очистке |
| 4 | Изменить даты | Пересчитываются счётчики, время и выручка |
| 5 | Выбрать город/станцию | В таблице остаются устройства подходящей области |
| 6 | Нажать устройство | Открывается список программ конкретного устройства |

#### ТК-PROG-02 — расчёт отображаемых показателей

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть строку с программами | Видны название, число запусков, общее/среднее время и выручка |
| 2 | Сверить total | Суммарный счётчик равен сумме программ устройства |
| 3 | Проверить среднее время | Среднее вычислено по числу запусков, при нуле нет деления на ноль |
| 4 | Проверить страницу без данных | Отображается empty state, график не содержит фиктивных значений |

## 2. Программы станции — `/station/programs/devices`

### О странице

| Вопрос | Ответ |
|---|---|
| **Зачем** | Определить, какое устройство и какая программа формируют загрузку и выручку станции. |
| **Что менеджерит** | Детализацию запусков программ по устройствам выбранного POS. |
| **Кто пользуется** | Менеджер станции, операционный руководитель и аналитик. |
| **Связи** | POS, устройства, программы, город, тип операции и период. |
| **Правила** | Нужен `posId`; фильтры передаются в запрос; переход к журналу сохраняет даты и тип операции. |

### Тест-кейсы

#### ТК-PROG-03 — фильтрация и переходы

**Предусловия:** в URL есть `posId`, период и доступные устройства.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть страницу | Загружается таблица устройств и раскрываемые данные программ |
| 2 | Переключить тип операции | Таблица обновляется, номер страницы сбрасывается |
| 3 | Изменить период или город | Запрос получает новые фильтры |
| 4 | Открыть устройство | URL содержит его `deviceId`, даты и тип операции |
| 5 | Изменить размер страницы | Список обновляется с выбранным размером |

## 3. Операции программного устройства — `/station/programs/device`

### О странице

| Вопрос | Ответ |
|---|---|
| **Зачем** | Проверять фактическое выполнение программ и сопоставлять запуски с депозитами. |
| **Что менеджерит** | Просмотр отдельных запусков: программа, начало/конец, длительность, local ID, тип оплаты и автомобиль. |
| **Кто пользуется** | Технический специалист, менеджер станции и финансовый контролёр. |
| **Связи** | Программное устройство, POS, депозиты и тип операции `PAYMENT`/`CLEANING`. |
| **Правила** | Нужен корректный `deviceId`; журнал доступен только для просмотра; даты начала и конца должны отображаться раздельно. |

### Тест-кейсы

#### ТК-PROG-04 — журнал запусков

**Предусловия:** задан корректный `deviceId`, есть события за период.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть страницу из списка | Загружаются операции выбранного устройства |
| 2 | Выбрать `PAYMENT`/`CLEANING` | Отображаются только операции выбранного типа |
| 3 | Изменить даты | Длительность и список соответствуют новому диапазону |
| 4 | Проверить начало и конец | Даты форматированы и не перепутаны |
| 5 | Проверить время | Время операции отображается в согласованном формате |
| 6 | Открыть без `deviceId` | Запрос не уходит с некорректным ID, показано безопасное состояние |
