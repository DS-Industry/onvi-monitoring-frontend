# Депозиты и операции устройств

## 1. Таблица депозитов сети — `/station/enrollments/table`

### О странице

| Вопрос | Ответ |
|---|---|
| **Зачем** | Сверять выручку сети и находить станции с аномальными суммами. |
| **Что менеджерит** | Финансовые показатели и операции по каналам наличных, безналичных, ONVI и Yandex. |
| **Кто пользуется** | Финансовый менеджер, региональный менеджер и аналитик. |
| **Связи** | Организация, страна, город, POS, период и детальные депозиты станции. |
| **Правила** | Суммы фильтруются по выбранному периоду; переход к деталям сохраняет `posId` и даты. |

### Тест-кейсы

#### ТК-DEP-01 — фильтры и таблица

**Предусловия:** выбрана страна, есть депозиты минимум у двух станций.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть URL с `countryId`, датами | Загружаются строки станций и итоговое количество |
| 2 | Выбрать город/станцию | Запрос отправляет соответствующие `placementIds`/`posIds`; таблица фильтруется |
| 3 | Изменить даты | Суммы и количество операций пересчитываются |
| 4 | Изменить размер страницы | Размер страницы меняется, номер страницы сбрасывается |
| 5 | Нажать название станции | Открываются детальные депозиты с сохранёнными датами и `posId` |

#### ТК-DEP-02 — денежные значения

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Сравнить сумму каналов со сводным результатом backend | Значения отображаются без потери дробной части |
| 2 | Выбрать валюту отображения | Значения конвертируются единообразно, исходная сумма операции не изменяется |
| 3 | Проверить пустой период | Таблица показывает `Нет данных`, пагинация не создаёт фиктивные строки |

## 2. Депозиты станции — `/station/enrollments/devices`

### О странице

| Вопрос | Ответ |
|---|---|
| **Зачем** | Понять, какое устройство передаёт финансовые данные станции и где возникают расхождения. |
| **Что менеджерит** | Список депозитных устройств и объём операций за период. |
| **Кто пользуется** | Менеджер станции, технический специалист и финансовый контролёр. |
| **Связи** | POS, placement/город, валюта и журнал операций устройства. |
| **Правила** | Нужен `posId`; изменение дат и города обновляет список; переход открывает выбранный `deviceId`. |

### Тест-кейсы

#### ТК-DEP-03 — список устройств

**Предусловия:** открыть маршрут с `posId` или перейти из станции.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть страницу | Загружается список устройств, даты по умолчанию корректны |
| 2 | Выбрать даты и город | Запрос мониторинга получает новые параметры |
| 3 | Использовать сортировку/выбор колонок | Сортировка и видимость колонок применяются только к таблице |
| 4 | Перейти по имени устройства | Открывается `/station/enrollments/device` с `deviceId`, `posId` и датами |
| 5 | Проверить недоступный `posId` | Данные не подменяются данными другой станции, показано пустое/ошибочное состояние |

## 3. Операции депозитного устройства — `/station/enrollments/device`

### О странице

| Вопрос | Ответ |
|---|---|
| **Зачем** | Сверять операции конкретного устройства и диагностировать задержки загрузки, дубли или ошибки. |
| **Что менеджерит** | Просмотр суммы, дат операции/загрузки, счётчика, local ID и валюты. |
| **Кто пользуется** | Финансовый контролёр, технический специалист и менеджер станции. |
| **Связи** | Депозитное устройство, POS, период, валюта и журнал device operations. |
| **Правила** | Нужен корректный `deviceId`; фильтр валюты влияет на запрос; запись на странице не редактируется. |

### Тест-кейсы

#### ТК-DEP-04 — просмотр операций

**Предусловия:** задан корректный `deviceId`, есть операции.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть страницу из списка | Загружается журнал выбранного устройства |
| 2 | Изменить период | Выводятся только операции в новом диапазоне |
| 3 | Выбрать валюту | Фильтр currency применяется к запросу и строкам |
| 4 | Перейти на другую страницу | Загружается соответствующая страница без потери фильтров |
| 5 | Сравнить дату операции и дату загрузки | Обе даты показаны отдельно и форматированы корректно |
| 6 | Открыть с `deviceId=0`/без ID | Запрос устройства не выполняется, показано безопасное пустое или ошибочное состояние |
