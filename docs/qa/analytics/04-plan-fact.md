# План/факт станции — `/station/plan/act`

## О странице

| Вопрос | Ответ |
|---|---|
| **Зачем** | Задавать месячные цели станции и контролировать их выполнение. |
| **Что менеджерит** | Месячный денежный план; фактическая выручка по каналам оплаты только просматривается. |
| **Кто пользуется** | Управляющий станцией, руководитель сети и аналитик. |
| **Связи** | POS, месяц, депозиты, каналы оплаты и сводка Plan/Fact в карточке станции. |
| **Правила** | Нужны `posId` и период; план не может быть отрицательным; сохранение требует `update`/`manage` на `Pos`. |

## Тест-кейсы

### ТК-PLAN-01 — загрузка таблицы

**Предусловия:** URL содержит `posId`, `dateStart`, `dateEnd`; у станции есть месячные данные.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть страницу | Загружаются строки месяцев выбранного диапазона |
| 2 | Проверить столбцы | Видны месяц, план, наличные, безналичные, Yandex, ONVI, итоговый факт и проценты |
| 3 | Проверить сортировку | Месяцы идут хронологически |
| 4 | Скрыть/показать колонки | Меняется только представление таблицы |
| 5 | Открыть без обязательного фильтра | Основной запрос не выполняется, показано корректное состояние |

### ТК-PLAN-02 — изменение месячного плана

**Предусловия:** есть право `update` или `manage` на `Pos`.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Изменить план месяца на положительное число | Значение изменено локально, кнопка Save становится активной |
| 2 | Ввести отрицательное число | InputNumber не принимает значение ниже нуля |
| 3 | Нажать Save | Отправлен PATCH месячного плана с `monthDate` и `monthlyPlan` |
| 4 | Дождаться ответа | Таблица обновлена, показано уведомление об успехе |
| 5 | Повторно открыть страницу | Сохранённое значение загружено из backend |
| 6 | Смоделировать ошибку сохранения | Показано уведомление об ошибке, состояние не маскирует сбой |
| 7 | Открыть без права изменения | Просмотр доступен согласно `read`, редактирование/сохранение недоступно или запрещено |

## Связь с карточкой станции

На вкладке Plan/Fact карточки отображаются агрегаты и прогресс за период. Ссылка **Перейти к полной таблице** ведёт на этот экран с теми же `posId`, `dateStart` и `dateEnd`; после изменения плана итоговый прогресс должен пересчитываться в overview.
