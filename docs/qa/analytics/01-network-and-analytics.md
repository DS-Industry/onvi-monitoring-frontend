# Analytics: сеть и карточка станции

## 1. Сеть станций — `/station/enrollments`

### О странице

| Вопрос | Ответ |
|---|---|
| **Зачем** | Контролировать показатели сети: выручку, число моек и выполнение плана за выбранный период. |
| **Что менеджерит** | Операционный мониторинг POS-станций и переход к деталям; не справочник POS. |
| **Кто пользуется** | Владельцы сети, региональные менеджеры и аналитики. |
| **Связи** | POS, организация, страна/город, месячный план и карточка конкретной станции. |
| **Правила** | Нужен `countryId`; фильтры и период влияют на KPI и карточки; доступ — `read`/`manage` на `Pos`. |

### Тест-кейсы

#### ТК-NET-01 — загрузка сети с фильтрами

**Предусловия:** есть станции в выбранной организации и данные за период.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `/station/enrollments` | Загружается заголовок сети, фильтры, период и конвертер валют |
| 2 | Выбрать страну | Выполняются запросы summary и cards; KPI и карточки станций заполнены |
| 3 | Выбрать город | Список и KPI пересчитываются для выбранного города |
| 4 | Ввести поиск по названию | Остаются подходящие станции; запрос получает параметр поиска |
| 5 | Переключить период | Обновляются даты в URL и данные соответствуют новому периоду |
| 6 | Перейти на следующую страницу | Показывается следующая порция карточек, размер страницы сохраняется |

#### ТК-NET-02 — пустое состояние и ошибка

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть экран без `countryId` | Основной запрос не выполняется, показано сообщение о выборе страны |
| 2 | Выбрать страну без станций | Показано штатное `Нет данных`, без пустых карточек |
| 3 | Смоделировать ошибку API | Показан alert ошибки, приложение не падает |

#### ТК-NET-03 — переход в станцию

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Нажать карточку станции | Открывается `/station/enrollments/:posId` |
| 2 | Проверить URL | Переданы `posName`, выбранный период и контекст фильтров |
| 3 | Нажать назад | Возврат в сеть с сохранёнными фильтрами и периодом |

## 2. Карточка станции — `/station/enrollments/:posId`

### О странице

| Вопрос | Ответ |
|---|---|
| **Зачем** | Анализировать работу одной станции в едином экране: выручку, загрузку, депозиты, лояльность и план/факт. |
| **Что менеджерит** | Представление агрегатов станции и навигацию по вкладкам; редактирование POS выполняется в отдельном управлении объектами. |
| **Кто пользуется** | Менеджер станции, региональный руководитель и аналитик с доступом к POS. |
| **Связи** | POS-профиль, device operations, программы, депозиты, лояльность, месячный план и сеть станций. |
| **Правила** | Нужен числовой `posId`; вкладка Cleaning скрыта для Portal; все вкладки используют общий период и валюту. |

### Тест-кейсы

#### ТК-STA-01 — вкладки и период

**Предусловия:** существует `posId` станции.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `/station/enrollments/123` | Загружается имя станции и вкладка Overview |
| 2 | Переключить период | Обновляются KPI, графики и данные активной вкладки |
| 3 | Переключить валюту | Денежные значения пересчитаны только для отображения |
| 4 | Открыть Deposits, Loyalty, Plan/Fact, Programs | Активная вкладка записывается в `tab`, загружается её контент |
| 5 | Открыть невалидный `posId` | Показана ошибка с возможностью вернуться к сети |

#### ТК-STA-02 — состав Overview

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть Overview | Видны выручка, возвраты, количество моек, визиты ONVI/карты |
| 2 | Проверить график | Динамика выручки соответствует выбранному периоду |
| 3 | Проверить структуру услуг | Доли/суммы услуг отображаются, при отсутствии данных — empty state |
| 4 | Открыть станцию типа Portal | Вкладка Cleaning отсутствует |
| 5 | Открыть SelfService-станцию | Вкладка Cleaning доступна |

#### ТК-STA-03 — пользовательские баннеры

**Предусловия:** для станции включена возможность custom banners и есть право изменения.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть Overview | Видны карточки Home/Header banner |
| 2 | Загрузить допустимый файл | Файл отправлен через presigned upload, URL сохранён, карточка обновлена |
| 3 | Загрузить недопустимый файл или отменить | Показана валидация/отмена, старое значение не повреждено |
| 4 | Открыть экран без feature flag | Блок баннеров не отображается |
