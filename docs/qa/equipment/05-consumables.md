# Расходники объекта — сценарии для тестировщика

> Меню: **Оборудование → Расходники объекта**.  
> Формат ТК: **Предусловия → Шаги → Ожидаемый результат**.

Общие предусловия раздела: план **BUSINESS / CUSTOM**, `read` или `manage` на `Incident`.

Связь номенклатур склада с химией/запчастями объекта. ТК склада не писать — только эта привязка.

---

## О странице

### Список (`/equipment/object-consumables`)

| | |
|--|--|
| **Зачем** | Привязать номенклатуру склада к типу химии или запчасти на объекте. |
| **Что менеджерит** | `TechConsumables`. API: `getTechConsumables`, `createTechConsumables`, `deleteTechConsumables`. Номенклатура: `getNomenclature` (склад). |
| **Кто пользуется** | Техслужба с доступом к экрану. Добавление: `create` или `manage` Incident. Удаление на UI без `Can`. |
| **Связи** | Отчёт по расходу берёт строки расходников; химические типы (не **Запасные детали**) получают `quantityByReport` из chemistry spent. |
| **Правила** | Query: `posId` (обязателен для загрузки), `type`. Типы: **Запасные детали**, **Химия "Щетка + Пена"**, **T-POWER**, **Вода + Шампунь**, **Воск + Защита**, **Активная химия**, **Мойка дисков**, **Соль**. |

Колонки: **Наименование**, **Тип**. Кнопки: **Добавить строку**, **Удалить выбранное**. Модалка: **Добавить расходный материал**.

---

## ТК-C1. Привязать номенклатуру склада к химии / запчасти

**Предусловия:** `create` или `manage` Incident; выбран `posId`; в организации есть номенклатура склада.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть **Расходники объекта**, выбрать объект | Таблица связей (или пустая) |
| 2 | **Добавить строку** | Модалка **Добавить расходный материал**: номенклатура + **Тип** |
| 3 | Выбрать номенклатуру и тип (химия или **Запасные детали**) → сохранить | **Запись успешно создана**. Строка с именем и переводом типа |
| 4 | Повторить ту же номенклатуру | В селекте её нет (`existingNomenclatureIds`) |

---

## ТК-C2. Удалить связь

**Предусловия:** есть хотя бы одна строка.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Отметить строки | Кнопка **Удалить выбранное (N)** активна |
| 2 | Подтвердить удаление | **Запись успешно удалена**. Связь пропадает из списка |

ТК документов склада и остатков — в [Склад](../warehouse/README.md), не здесь.
