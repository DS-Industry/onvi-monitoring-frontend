# Простой платежных устройств — сценарии для тестировщика

> Меню: **Оборудование → Простой платежных устройств**.  
> Формат ТК: **Предусловия → Шаги → Ожидаемый результат**.

Общие предусловия раздела: план **BUSINESS / CUSTOM**, `read` или `manage` на `Incident`.

Только просмотр. Алгоритм на сервере. Создания записей простоя в UI нет.

---

## О странице

### Таблица (`/equipment/idle-payment-devices`)

| | |
|--|--|
| **Зачем** | Смотреть рассчитанные простои постов и каналов оплаты. |
| **Что менеджерит** | Нет CRUD. API: `getDowntime` (`GET user/device/downtime`). |
| **Кто пользуется** | Техслужба с `read` Incident. |
| **Связи** | Независимый экран. Не путать с полем **Простой** в форме поломки. |
| **Правила** | Query: `dateStart`, `dateEnd`, `cityIds`, `posIds`, `downtimeType` (дефолт **Монетник** / `COIN`), `page`, `size`. Can нет. |

Типы фильтра: **Монетник**, **Купюрник**, **Безналичная оплата**, **Пост**. Колонки каналов: **Тип**, **Период простоя**, **Время простоя, ч**, **Кол-во операций на других устройствах**. Алгоритм: lookback 60 дней, gap > 12 ч, соседи на POS.

---

## ТК-D1. Только просмотр

**Предусловия:** `read` Incident.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть **Простой платежных устройств** | `/equipment/idle-payment-devices`, заголовок «Простой платежных устройств» |
| 2 | Дождаться загрузки | Таблица постов/устройств или пустая. Строки можно развернуть на каналы |
| 3 | Искать создание, сохранение, удаление | Таких кнопок нет |

---

## ТК-D2. Фильтры

**Предусловия:** экран открыт.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Задать период | `dateStart`, `dateEnd` в запросе |
| 2 | Город / объекты (мульти) | `cityIds`, `posIds` |
| 3 | **Тип устройства**: купюрник / безнал / пост | `downtimeType` = `PAPER` / `POS` / `DEVICE`. Без выбора в URL подставляется `COIN` |
| 4 | Пагинация | `page`, `size` |

---

## ТК-D3. Без кнопок «создать»

**Предусловия:** любой пользователь с доступом к экрану.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Осмотреть шапку и таблицу | Нет **Создать** / **Добавить** / **Зафиксировать** для простоя |
| 2 | Network | Только GET `user/device/downtime`, без POST |
