# Расход химии — сценарии для тестировщика

> Меню: **Оборудование → Расход химии**.  
> Формат ТК: **Предусловия → Шаги → Ожидаемый результат**.

Общие предусловия раздела: план **BUSINESS / CUSTOM**, `read` или `manage` на `Incident`.

Цепочка: техзадачи с тегом химии + норма расхода. Тег в коде — `TECH_RATE` ([00-how-it-works.md](./00-how-it-works.md)).

---

## О странице

### Отчёт (`/equipment/chemical/consumption`)

| | |
|--|--|
| **Зачем** | Информационный отчёт: факт программ + заполненные техзадачи, график расхода/залива. Выводы делает техник. |
| **Что менеджерит** | Нет сущности «документ химии». API: `getChemicalReport` (`GET user/tech-task/chemistry-report`). |
| **Кто пользуется** | Все техники с `read` Incident. |
| **Связи** | FINISHED-задачи с `code=TECH_RATE`; `ProgramTechRate` объекта. Не пишет склад и статьи. |
| **Правила** | Query: `posId`, `dateStart`, `dateEnd`, `city`. Нужен объект. Кнопок create/save нет. Can на странице нет. |

Колонки периода и типы: **Вода + шампунь**, **Активная химия**, **Мойка дисков**, **Щетка + пена**, **Воск + защита**, **T-POWER** — факт / время / пересчет. Раскрытие: **Тип химии**, **Факт**, **Пересчет**, **Время**, **График**, **Уровень химии**. Модалки: **График потребления**, **Уровень химии**, **Залив**. Пусто: **Нет данных**.

Backend: ≥ 2 FINISHED-задач с тегом за период. `spent` и `recalculation` — формулы в how-it-works.

---

## ТК-H1. Открыть отчёт

**Предусловия:** `read` Incident; выбран объект; в периоде есть данные (или пусто — тоже валидно).

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | **Оборудование → Расход химии** | `/equipment/chemical/consumption`, заголовок «Расход химии» |
| 2 | Выбрать объект и период | Уходит `posId`, `dateStart`, `dateEnd` (и `city` если задан) |
| 3 | Дождаться ответа | Таблица периодов или пустая. Нет кнопок создать/отправить |

---

## ТК-H2. График

**Предусловия:** в отчёте есть строки с `chartData` / уровнем.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Развернуть период | Вложенная таблица типов химии |
| 2 | Открыть мини-график / модалку | Заголовок **График потребления** или **Уровень химии**; оси факт/пересчет или уровень/залив |
| 3 | Нет точек | **Нет данных** / **Нет данных для отображения** |

---

## ТК-H3. Без нормы / без задач с тегом

**Предусловия:** тот же объект и период.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Период, где нет ≥ 2 FINISHED-задач с `code=TECH_RATE` | Отчёт пустой или без spent по химии — **факт кода**, не ошибка UI |
| 2 | Нормы `literRate` / `concentration` пустые или 0 | Пересчет 0 / пустой (`coef = literRate / concentration`); Portal — coef 0 |
| 3 | Задачи с тегом по **имени** «Расход химии», но без `code=TECH_RATE` | В chemistry-report не входят |
