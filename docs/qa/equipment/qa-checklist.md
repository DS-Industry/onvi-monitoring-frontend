# Оборудование — QA checklist (Pass / Fail)

Отмечайте: Pass / Fail / Blocked / N/A.  
Детальные шаги — в файлах `01`–`08`.

**Предусловия:** BUSINESS\|CUSTOM; организация; права экрана (`Incident`, `TechTask`).

Smoke: задачи с тегом химии → нормы → расход химии; задачи + нормы + расходники → отчёт → списание склада; поломка; моточасы; простой.
