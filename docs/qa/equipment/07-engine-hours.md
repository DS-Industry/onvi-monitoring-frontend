# Моточасы — сценарии для тестировщика

> Меню: **Оборудование → Моточасы**.  
> Формат ТК: **Предусловия → Шаги → Ожидаемый результат**.

Общие предусловия раздела: план **BUSINESS / CUSTOM**, `read` или `manage` на `Incident`.

Главный техник задаёт лимиты и дату замены масла; наработка по времени программ; превышение помечается.

---

## О странице

### Таблица (`/equipment/engine-hours`)

| | |
|--|--|
| **Зачем** | Видеть наработку помпы/масла и править техпараметры устройства. |
| **Что менеджерит** | Расчёт GET `user/device/tech-params/engine-hours`; PATCH `user/device/tech-params/{deviceId}`. |
| **Кто пользуется** | Главный техник (правка полей в таблице). Can на кнопки **нет** — edit доступен всем, кто открыл экран. |
| **Связи** | Независимый экран. Устройства типа WASHER. |
| **Правила** | Query: `dateStart`, `dateEnd`, `cityIds`, `posIds`, `excess`, `page`, `size`. Фильтр **Превышение** уходит в API, backend **не фильтрует**. Пометка превышения — красный цвет `oilRunHours > oilLimit` на UI. |

Колонки: **Автомойка/ Филиал**, **Устройство**, **Версия помпы**, **Уставка масла**, **Время работы помпы**, **Наработка масла с последней замены масла**, **Наработка масла с последней замены помпы**, **Предыдущая замена масла**, **Предыдущая замена помпы**. Колонка помпы масла на бэке **не заполняется**.

---

## ТК-M1. Лимиты и дата замены масла

**Предусловия:** есть WASHER на объекте.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть **Моточасы**, задать период | Таблица устройств |
| 2 | Задать **Уставка масла** (клик, число, blur) | PATCH, значение сохраняется |
| 3 | Задать **Предыдущая замена масла** | Дата-время сохраняется; **Наработка масла с последней замены масла** считается от этой даты до сегодня 23:59 по кодам программ версии помпы |
| 4 | Сменить **Версия помпы** 1 / 2 | Меняется набор программ в наработке (v1: SOAP, WATER; v2: SOAP, TIRE, PRESOAK, BRUSH, WATER, WAX, OSMOS) |

---

## ТК-M2. Превышение

**Предусловия:** у устройства заданы уставка и наработка масла больше уставки.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Смотреть **Наработка масла с последней замены масла** | Число красным, если `oilRunHours > oilLimit` |
| 2 | Фильтр **Превышение** | Query `excess=EXCESS`. Список на сервере **не** сужается — факт кода. Пометка остаётся клиентской |
