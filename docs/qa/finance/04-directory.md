# Справочник статей — сценарии для тестировщика

> Меню: **Управление → Финансовый учет → Справочник статей**.  
> Формат ТК: **Предусловия → Шаги → Ожидаемый результат**.

Общие предусловия: план **SPACE / BUSINESS / CUSTOM**, организация, права `ManagerPaper`.

«Особые права» в продукте = `manage` **или** `update` на `ManagerPaper` (так проверяет UI). На backend create/update типа — action **`update`**. Delete типа **нет**.

---

## О странице

### Справочник статей (`/finance/financial/accounting/directory/articles`)

| | |
|--|--|
| **Зачем** | Завести типы статей (имя + приход/расход), которые выбирают на экране **Статьи**. |
| **Что менеджерит** | `ManagerPaperType`. API: `getAllManagerPaperTypes`, `createManagerPaperType`, `updateManagerPaperType`. |
| **Кто пользуется** | Пользователь с особыми правами (`manage` или `update`). Просмотр списка — `read` на маршруте. |
| **Связи** | Статьи; автотипы «Инкассация» / «Продажа» живут в seed, с этого экрана их не «проводят». |
| **Правила** | Query-параметров нет. Удаления типа в UI и API нет. `Can` не используется — только `hasPermission`. |

Таблица: **id**, имя (`equipment.name`), **Тип статьи** (теги **Приход** / **Расход**). Drawer: имя, тип*.

---

## ТК-D1. Список типов

**Предусловия:** `read` или `manage` на маршрут (сайдбар **Справочник статей**).

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть **Справочник статей** | `/finance/financial/accounting/directory/articles`, таблица типов |
| 2 | Проверить колонки | id, название, приход или расход |

---

## ТК-D2. Создать и править тип при особых правах

**Предусловия:** `manage` или `update` на `ManagerPaper`.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Нажать добавление | Drawer, поля имя и **Тип статьи** |
| 2 | Сохранить без имени / типа | Валидация |
| 3 | Имя + **Приход** → сохранить | Строка в таблице; тип доступен в модалке статей |
| 4 | Карандаш → сменить имя или на **Расход** → сохранить | Строка обновлена |

---

## ТК-D3. Без прав — нет управления

**Предусловия:** есть `read` на `ManagerPaper`, **нет** `update` и `manage`.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть справочник | Список можно увидеть (если маршрут пустил по `read`) |
| 2 | Искать добавление и карандаш | Кнопок управления **нет** (`allowed === false`) |

Если нет даже `read`/`manage` на пункте меню — пункта **Справочник статей** в сайдбаре нет.

---

## Краткая справка (для отладки)

- `GET/POST/PATCH user/manager-paper/type`. Delete типа нет.
- Feature: `ManagerPaper`. CASL на запись типа: `update`.
