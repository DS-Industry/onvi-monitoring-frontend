## Полный smoke раздела

Порядок:

1. **Отсечка (опц.)** — ТК-T1–T2 или пропуск (ТК-T4).
2. **Инкассация:** сформировать → факт → положительная недостача, если факт меньше расчёта → **Пересчитать и отправить** → только **Вернуть**.
3. **Статья** типа инкассация появилась, не редактируется.
4. **Отчет за период** по этому пользователю: статьи (в т.ч. с разных объектов) видны. Пустой период — норма (ТК-P3).
5. **Табель:** создать рабочую смену → оценка → размен/возврат при необходимости → отправить → только вернуть.
6. **Продажа:** с остатком и ценой провести → статья; без возврата нельзя править; вернуть → статья снята.
7. **Отладка:** список ложных → устройство → удалить; загрузка файла техником.
8. **Партнёры:** проценты 100% → месячный отчёт с excel → смена % не трогает старый → **Мои Отчеты** только свои.

Табель на статьи не влияет. Исключения долей ≠ 100% «только разработчик» не прогонять.
