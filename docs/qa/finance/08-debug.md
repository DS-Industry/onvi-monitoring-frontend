# Отладка — сценарии для тестировщика

> Меню: **Управление → Отладка**.  
> Формат ТК: **Предусловия → Шаги → Ожидаемый результат**.

Общие предусловия: план **SPACE / BUSINESS / CUSTOM**, организация, права `Pos`.  
Пользователь: управляющий или техник объекта. Отдельной сущности «false deposit» нет: эвристика **false-operations** + удаление операций устройства.

---

## О странице

### Ложные зачисления — список (`/finance/debugging/false/deposits`)

| | |
|--|--|
| **Зачем** | Найти возможные ошибочные зачисления по объекту (алгоритм по операциям). |
| **Что менеджерит** | Агрегат по устройствам. API: `getFalseDepositDevice` → `GET /user/pos/false-operations/{posId}`. |
| **Кто пользуется** | `read` / `manage` на `Pos`. |
| **Связи** | Карточка устройства; удаление влияет на статистику и документы, которые читают эти операции. |
| **Правила** | Query: `posId`, `dateStart`, `dateEnd`. Нужен выбранный объект. Колонки: устройство, число, день. |

### Карточка устройства (`/finance/debugging/false/deposit`)

| | |
|--|--|
| **Зачем** | Разобрать операции устройства, отметить ложные, удалить чтобы не учитывать. |
| **Что менеджерит** | `GET /user/device/false-operations/{deviceId}`; `deleteFalseOperations` → `DELETE /user/device/operations` `{ ids }`. |
| **Кто пользуется** | Маршрут: + `delete` на `Pos`. Удаление: `manage\|delete` Pos. Заголовок «Ложный кредит». |
| **Связи** | Список ложных; это **общее** удаление операций, не отдельная таблица. |
| **Правила** | Query: `deviceId`, `dateStart`, `dateEnd`, `page`, `size`. Чекбокс и подсветка только у `falseCheck`. Удаление только отмеченных ложных. |

Эвристика backend: COIN > 2 / PAPER > 1 в одну секунду; POS-окно ≤ 5 сек.

### Загрузка файла с операциями (`/finance/debugging/device-data-raw/upload`)

| | |
|--|--|
| **Зачем** | Загрузить сырые данные, которые не дошли с оборудования. Грузит техспециалист объекта. |
| **Что менеджерит** | Presign S3 + `registerDeviceDataRawFile` → `POST /user/device/data-raw-file` `{ key }`. Ключ `device-data-raw/{timestamp}-{filename}`. |
| **Кто пользуется** | `read` / `manage` на `Pos`. |
| **Связи** | С ложными зачислениями **не** связан. |
| **Правила** | Query нет. Dragger, несколько файлов; фильтра расширения в коде нет. |

---

## ТК-F1. Список ложных зачислений

**Предусловия:** `read` или `manage` на `Pos`; на объекте есть операции за период.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | **Управление → Отладка → Ложные зачисления** | `/finance/debugging/false/deposits`, заголовок «Ложные зачисления» |
| 2 | Выбрать объект и даты | Строки по устройствам (или пусто, если эвристика ничего не нашла) |

---

## ТК-F2. Открыть устройство

**Предусловия:** в списке есть строка устройства.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть устройство | `/finance/debugging/false/deposit?deviceId=…`, операции за период |
| 2 | Смотреть ложные | Строки с `falseCheck` подсвечены, только их можно отметить |

---

## ТК-F3. Удалить (не в статистике / документах)

**Предусловия:** есть отмеченные ложные; `delete` или `manage` на `Pos`.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Отметить ложные → удалить | `DELETE /user/device/operations` с `ids` |
| 2 | Обновить список / карточку | Операций нет. В статистике и документах, которые читают операции устройства, их **не** учитывать |

---

## ТК-F4. Загрузка файла (техник)

**Предусловия:** `read` / `manage` на `Pos`; файл с операциями устройства.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | **Отладка → Загрузка файла с операциями** | `/finance/debugging/device-data-raw/upload`, заголовок «Загрузка файла с операциями» |
| 2 | Загрузить файл | Presign S3 (`POST /user/s3/presigned-url`), затем `POST /user/device/data-raw-file`. Успех без привязки к экрану ложных зачислений |

---

## Краткая справка (для отладки)

- False: `GET /user/pos/false-operations/{posId}`, `GET /user/device/false-operations/{deviceId}`, `DELETE /user/device/operations`.
- Raw: `POST /user/s3/presigned-url`, `POST /user/device/data-raw-file`.
- Subject: `Pos`. Отдельного finance-controller для этих экранов нет.
