# Программа лояльности — сценарии для тестировщика

> Меню: **Маркетинг → Программа лояльности**.  
> Это **центр** раздела Marketing: без программы карты, заказы и кампании «не к чему привязать».

---

## О странице

### Список (`/marketing/loyalty`)

| | |
|--|--|
| **Зачем** | Видеть программы, где организация — **владелец** или **участник**; создавать свою; подавать заявку на вступление; удалять свою. |
| **Что менеджерит** | Участие в **Loyalty program** (роль owner/participant, hub/regular, статусы). Backend: participant-programs, `loyaltyProgram-create/delete`, participant/hub request + approve/reject. |
| **Кто пользуется** | Админ орг-ции; delete/publish — только **owner**. |
| **Связи** | Wizard программы; дальше — карты, заказы, кампании этой программы. |
| **Правила** | Non-owner не удаляет и ограничен в edit. Join — через заявку, не мгновенное «вступление без апрува» (зависит от approve flow). |

### Wizard create/edit (`/marketing/loyalty/program`, `/:id`)

| | |
|--|--|
| **Зачем** | Настроить программу: базовые данные, POS-участники, уровни (tiers) и benefits, правила списания бонусов, публикация, аналитика. |
| **Что менеджерит** | Program + tiers + benefits/benefitActions + bonus redemption rules + participant poses + publish/unpublish + analytics. Backend: `loyaltyProgram-create/update`, tier CRUD, benefit CRUD, `loyalty-program-update-bonus-redemption-rules`, `loyalty-program-get-participant-poses`, `loyalty-program-publish/unpublish`, analytics use-cases. |
| **Кто пользуется** | Owner — полный контроль; participant — ограниченный просмотр/edit. |
| **Связи** | Список программ; импорт карт (нужен tier); кампании выбирают программу. |
| **Правила** | Publish только owner. Stats-шаг только в `mode=edit`. Клик Steps только в edit. |

## ТК-L1. Открыть список программ

**Предусловия:** `read` LTYProgram.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Маркетинг → **Программа лояльности** | Список программ |
| 2 | Проверить колонки | Название, статус, дата запуска, роль (Владелец/Участник), тип (Hub/обычная), филиалы, клиенты, действия |

---

## ТК-L2. Поиск, фильтры, вид

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Ввести текст в поиск | Список сужается |
| 2 | Фильтр по статусу / роли участия | Только подходящие программы |
| 3 | Переключить Таблица / Карточки | Тот же набор в другом виде |

---

## ТК-L3. Создать программу (wizard)

**Предусловия:** право создавать (`create`/`update` через Can).

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Нажать **Добавить** | `/marketing/loyalty/program`, шаг «Базовые данные» |
| 2 | Заполнить обязательные поля → далее | Программа создана, дальше шаги wizard |
| 3 | Шаг **Участники**: привязать POS (если owner) | Участники сохранены |
| 4 | Шаг **Уровни / бонусы**: создать уровень (tier), benefit | Уровни отображаются |
| 5 | Настроить правила списания бонусов (если есть) | Правила сохраняются |
| 6 | Шаг **Публикация** (только owner) | Можно **Опубликовать** / снять публикацию |
| 7 | Non-owner на чужой программе | Поля ограничены, публикации нет |
| 8 | Шаг **Статистика** | Появляется **только в режиме редактирования** существующей программы |

---

## ТК-L4. Редактировать программу

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Кликнуть по названию своей программы (owner) | Открывается wizard edit (`mode=edit` / `:id`) |
| 2 | Кликнуть по шагу в Steps | Переход на шаг |
| 3 | Изменить название → сохранить | В списке новое название |
| 4 | Как участник (не owner) | Редактирование ограничено; удаление недоступно |

---

## ТК-L5. Опубликовать / снять публикацию

**Предусловия:** owner.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | На шаге Публикация нажать опубликовать | Сообщение об успешной публикации |
| 2 | Снять публикацию | Сообщение об отмене публикации |

---

## ТК-L6. Вступить в программу (Join)

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Нажать **Вступить** / Join | Открывается модалка выбора публичной программы |
| 2 | Выбрать программу → отправить заявку | Заявка создана (статус ожидания у владельца) |
| 3 | Отмена в модалке | Заявка не создана |

---

## ТК-L7. Удалить программу

**Предусловия:** вы owner программы.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | В действиях нажать **Удалить** | Confirm |
| 2 | Подтвердить | Программа исчезает из списка, toast успеха |
| 3 | Как участник (не owner) | Кнопки удаления нет |
