## О странице

### Задумка продукта

| | |
|--|--|
| **Зачем (целевое)** | Сегментировать аудиторию клиентов (критерии отбора) для кампаний и коммуникаций — «кому показывать акцию». |
| **Что менеджерит сейчас** | **Ничего на backend**: роут списка рендерит `Default` (заглушка); `NewSegment` — UI-макет без save API. В `loyalty-core` нет готового сегмент-модуля, подключённого к этим экранам. |
| **Кто пользуется** | По роуту — `manage` LTYProgram; фактически feature недоступна как продукт. |
| **Связи (будущие)** | Кампании, клиенты — пока не связаны. |
| **Правила QA** | Отсутствие persistence и списка — **не дефект**. Файл `Marketing/Segments.tsx` в роутинг не подключён. |

## ТК-S1. Список сегментов — заглушка

**Предусловия:** право `manage` LTYProgram (для доступа к роуту).

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть `/marketing/segments` | Экран-заглушка («скоро» / Default), **не** полноценный список сегментов |
| 2 | Обновить страницу | То же поведение |
| 3 | Не ожидать CRUD / API | Отсутствие сохранения — **не баг** |

## ТК-S2. Новый сегмент — UI без сохранения

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть `/marketing/segments/new` | Открывается конструктор критериев (переключатели, подписи) |
| 2 | Включить/выключить критерии | UI реагирует |
| 3 | Открыть диалог выбора колонок (если есть) | Диалог открывается; опции могут быть пустыми |
| 4 | Обновить страницу | Настройки **сбрасываются** — сохранения в API нет |
| 5 | Искать кнопку «Сохранить», которая пишет на сервер | Отсутствует / не работает — ожидаемо для WIP |
