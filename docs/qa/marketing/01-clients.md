# Клиенты — сценарии для тестировщика

> Меню: **Маркетинг → Клиенты**.  
> Формат ТК: **Предусловия → Шаги → Ожидаемый результат**.

Общие предусловия раздела: план **BUSINESS** / **CUSTOM**, организация, права `LTYProgram`.

---

## О странице

### Список клиентов (`/marketing/clients`)

| | |
|--|--|
| **Зачем** | Вести базу клиентов лояльности организации: искать, создавать и править контакты, переходить в карточку клиента. |
| **Что менеджерит** | Сущность **Client** (имя, телефон, email, пол, дата рождения, комментарий, тип физ/юр, статус). Backend: `client-create`, `client-update`, `client-find-by-filter`, `client-get-by-id`. |
| **Кто пользуется** | Менеджер/админ организации с доступом к LTYProgram. |
| **Связи** | Профиль клиента; импорт карт; карты (**Пользователи**); при создании можно привязать карту. |
| **Правила** | Create/Edit/Import только при `update`/`manage`. Фильтр PHYSICAL→contract INDIVIDUAL, LEGAL→CORPORATE. |

### Импорт карт (`/marketing/clients/import`)

| | |
|--|--|
| **Зачем** | Массово завести карты (и связанных клиентов) из файла, не вбивая по одной. |
| **Что менеджерит** | Импорт в **Card** (+ связь с программой, tier, типом карты, опционально corporate). Backend: `card-import`. |
| **Кто пользуется** | Тот же менеджер с `update`. |
| **Связи** | Нужна программа лояльности и уровни (tiers); можно prefill corporate через query. |
| **Правила** | Обязательны файл + tier + cardType; лимит размера файла ~10 МБ; шаблон xlsx. |

### Профиль клиента (`/marketing/clients/profile`)

| | |
|--|--|
| **Зачем** | 360° по клиенту: данные, метрики, лояльность/карты, операции; soft-delete. |
| **Что менеджерит** | Client + stats + cards assign + card operations + soft-delete. Backend: `client-update`/`client-delete` (статус `DELETED`, карта → `INACTIVE`), notes/activity на смежных экранах карты. |
| **Кто пользуется** | Пользователь с `update` и/или `delete`. |
| **Связи** | Список клиентов; карта клиента; заказы (`from=orders`). |
| **Правила** | Без `userId` данные не грузятся. Удаление — **не hard DELETE**: статус DELETED. |

## ТК-C1. Открыть список клиентов

**Предусловия:** право `read` на LTYProgram.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | В боковом меню открыть **Маркетинг** | Раскрывается подменю |
| 2 | Нажать **Клиенты** | Открывается `/marketing/clients`, заголовок «Клиенты» |
| 3 | Дождаться загрузки | Таблица клиентов (или «Нет данных», если пусто). Есть колонки: Тип, Имя, Телефон, Статус, Комментарий |

---

## ТК-C2. Отфильтровать клиентов

**Предусловия:** в списке есть клиенты разных типов.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть Клиенты | Список загружен |
| 2 | В фильтрах выбрать тип **Физическое лицо** (PHYSICAL) | Таблица обновляется, в колонке Тип — физ. лица |
| 3 | Выбрать **Юридическое лицо** (LEGAL) | Только юр. лица |
| 4 | Указать период **Дата регистрации** | Список ограничен выбранными датами |
| 5 | Ввести текст в поиск (имя/телефон — как в фильтрах на странице) | Список сужается по запросу |
| 6 | Сбросить фильтры | Снова полный список |

---

## ТК-C3. Создать клиента

**Предусловия:** право `update` или `manage` на LTYProgram (иначе кнопки нет).

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Нажать **Добавить** | Справа/сбоку открывается drawer «Новый клиент» |
| 2 | Оставить имя и телефон пустыми → **Сохранить** | Ошибки валидации (имя и телефон обязательны) |
| 3 | Заполнить **Имя**, **Телефон** (валидный формат) | Поля приняты |
| 4 | По желанию: дата рождения, пол, email, комментарий, карта | Поля заполняются |
| 5 | Нажать **Сохранить** | Toast/сообщение об успехе, drawer закрывается, клиент есть в таблице |
| 6 | Нажать **Отменить** на новом открытии drawer без сохранения | Drawer закрывается, новый клиент не создаётся |

---

## ТК-C4. Редактировать клиента из списка

**Предусловия:** есть клиент, есть право update/manage.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | В строке клиента нажать иконку **Изменить** (карандаш) | Drawer «Изменить клиента» с заполненными данными |
| 2 | Изменить имя → **Сохранить** | Успех, в таблице новое имя |
| 3 | Без права update | Колонка с карандашом и кнопки Добавить/Импорт **не видны** |

---

## ТК-C5. Перейти в профиль клиента

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | В таблице кликнуть по **имени** клиента (ссылка) | Переход на `/marketing/clients/profile?userId=…` |
| 2 | Проверить заголовок | «Клиент» + имя клиента |
| 3 | Нажать **Назад** | Возврат к списку (или предыдущей странице) |

---

## ТК-C6. Импорт карт — переход и шаблон

**Предусловия:** право update/manage.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | На странице Клиенты нажать **Импортирование карт** | Открывается `/marketing/clients/import` |
| 2 | Скачать шаблон файла | Скачивается `client-cards-template.xlsx` (или аналог) |
| 3 | Загрузить файл > 10 МБ | Система отклоняется / ошибка размера |
| 4 | Загрузить валидный xlsx/xls/csv | Файл принят, можно открыть параметры импорта |

---

## ТК-C7. Импорт карт — успешный импорт

**Предусловия:** есть программа лояльности и уровни (tiers); файл по шаблону.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | После загрузки файла открыть форму параметров | Видны: программа, уровень (tier), тип карты, опционально корп. клиент |
| 2 | Не выбирать tier и card type → подтвердить | Импорт не проходит / ошибка обязательных полей |
| 3 | Выбрать программу, **уровень**, **тип карты** → подтвердить импорт | Успешное сообщение, карты/клиенты появились в системе |
| 4 | Открыть импорт с `?corporateClientId=` | Корп. клиент уже подставлен в форме |

---

## ТК-C8. Профиль клиента — вкладки и сохранение

**Предусловия:** открыт профиль с валидным `userId`; право update и/или delete.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть вкладку **Основное** (Базовое) | Форма данных клиента |
| 2 | Изменить поле → сохранить | Данные сохранились, после обновления страницы те же |
| 3 | Открыть вкладку **Ключ** (ключевые показатели) | Отображается статистика (или пустые значения) |
| 4 | Открыть **Лояльность** | Статистика лояльности / карты; можно назначить карту (если доступно) |
| 5 | Открыть **Операции** | Список операций по карте (или пусто) |
| 6 | Выполнить удаление/блокировку клиента (soft-delete → статус удалён), если кнопка есть | Клиент не «исчезает из БД hard», статус меняется на удалённый |

---

## ТК-C9. Профиль без userId / несуществующий

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть `/marketing/clients/profile` без `userId` | Данные клиента не загружаются / пустой профиль |
| 2 | Открыть с несуществующим `userId` | Ошибка или пустое состояние (зафиксировать фактическое поведение) |
