# Корпоративные клиенты — сценарии для тестировщика

> Меню: **Маркетинг → Корпоративные клиенты**.  
> Нужны тарифные фичи **LTYProgram + CORPORATE_CLIENTS**. Без них — placeholder, не полный CRUD.

---

## О странице

### Список (`/marketing/corporate-clients`)

| | |
|--|--|
| **Зачем** | Управлять **B2B-клиентами** лояльности: компании с ИНН, владельцем, привязкой к программе — отдельно от обычных физлиц. |
| **Что менеджерит** | Сущность **Corporate client** (название, ИНН, адрес, телефон владельца, даты, статус, программа). Backend: `corporate-create`, `corporate-update`, `corporate-find-by-filter`. |
| **Кто пользуется** | Менеджер орг-ции с тарифом CORPORATE_CLIENTS. |
| **Связи** | Профиль корп. клиента; импорт карт с `corporateClientId`; карты могут быть корпоративными. |
| **Правила** | Создание требует выбора **программы лояльности**. Без тарифа — заглушка. |

### Профиль (`/marketing/corporate-clients/profile`)

| | |
|--|--|
| **Зачем** | Карточка компании: статистика, пул карт, операции по картам, ручные бонус-операции. |
| **Что менеджерит** | Corporate + stats + cards + cards operations + bonus operations. Backend: `corporate-get-by-id`, `corporate-get-stats-by-id`, `corporate-get-cards`, `corporate-get-cards-operations` (+ bonus op на фронте). |
| **Кто пользуется** | Пользователь с `update` и тарифом. |
| **Связи** | Список корп. клиентов; карты; заказы/операции. |
| **Правила** | Нужен `clientId` в query. Бонус-операция — под `Can`. |

---

## ТК-K1. Открыть список (с тарифом)

**Предусловия:** тариф CORPORATE_CLIENTS, право `read` LTYProgram.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Маркетинг → **Корпоративные клиенты** | Открывается список, заголовок «Корпоративные клиенты» |
| 2 | Дождаться загрузки | Таблица: Название, ИНН, Адрес, Телефон владельца, Дата регистрации, Статус, Действия |

---

## ТК-K2. Открыть без тарифа

**Предусловия:** нет фичи CORPORATE_CLIENTS.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Зайти в Корпоративные клиенты | Показан **placeholder** тарифа, полноценный список/CRUD недоступен |

---

## ТК-K3. Фильтры списка

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Отфильтровать по ИНН | В списке только подходящие |
| 2 | По телефону владельца / названию / номеру карты | Список сужается |
| 3 | По датам регистрации | Список за период |
| 4 | Сбросить фильтры | Полный список |

---

## ТК-K4. Создать корпоративного клиента

**Предусловия:** тариф + право создавать/редактировать (обычно update).

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Нажать **Создать** | Открывается drawer/форма |
| 2 | Не выбрать программу лояльности → сохранить | Ошибка: программа лояльности обязательна |
| 3 | Заполнить обязательные поля + выбрать программу лояльности → сохранить | Успех, клиент в таблице |
| 4 | Отмена без сохранения | Клиент не создан |

---

## ТК-K5. Редактировать из списка

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | В строке нажать **Редактировать** | Форма с текущими данными |
| 2 | Изменить поле → сохранить | Данные в таблице обновились |

---

## ТК-K6. Перейти в профиль

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Кликнуть по названию / ссылке клиента | `/marketing/corporate-clients/profile?clientId=…` |
| 2 | Проверить загрузку | Имя/заголовок клиента (возможен skeleton при загрузке) |

---

## ТК-K7. Профиль — вкладки

**Предусловия:** валидный `clientId`, право `update`.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Вкладка с основной информацией | Данные корп. клиента |
| 2 | Вкладка статистики / ключ | Показатели по клиенту |
| 3 | Вкладка карт | Список карт корп. клиента |
| 4 | Вкладка **Операции** | Список операций; есть поиск |

---

## ТК-K8. Создать бонус-операцию

**Предусловия:** на вкладке Операции есть кнопка (права `Can`).

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Нажать **Создать операцию** (или аналог) | Открывается модальное окно |
| 2 | Заполнить тип, сумму, устройство и т.д. → подтвердить | Успех, операция появляется в списке |
| 3 | Без права на действие | Кнопки создания нет |

---

|-----|----------|---------------------|
