# Управление промокодами — сценарии для тестировщика

> Меню: **Маркетинг → Управление промокодами**.  
> Нужны тарифные фичи **LTYProgram + ONVI**. Без них — placeholder тарифа.

---

## О странице

### Управление промокодами (`/marketing/promo-code-management`)

| | |
|--|--|
| **Зачем** | Централизованно создавать и сопровождать **промокоды**: разовые/постоянные скидки и коды, которые клиент вводит на мойке или получает персонально / из кампании. |
| **Что менеджерит** | Сущность **Promocode** (код, тип скидки, значение, max/current usage, isActive, привязка к кампании или пользователю). Backend: `promocode-create/update/delete/find-methods` в `marketing-campaign`; выдача при заказах — `promocode-issue.service` в order domain. Типы фильтра: **standalone** / **campaign** / **personal**. |
| **Кто пользуется** | Менеджер с `update` и тарифом ONVI. |
| **Связи** | Кампании (условия PROMOCODE_ENTRY, campaign-промокоды); вкладка промокодов на карте клиента (personal); заказы (применение кода). |
| **Правила** | Без ONVI — placeholder. Вкладка manual transaction в UI **отключена** (API может существовать). Удаление campaign-промокода может показывать предупреждение. |

---

## ТК-P1. Открыть с тарифом ONVI

**Предусловия:** тариф ONVI, право `update` LTYProgram.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть **Управление промокодами** | Заголовок раздела, вкладка **Промокод** |
| 2 | Дождаться загрузки | Таблица промокодов (код, тип, скидка, лимиты, статус, действия) |
| 3 | Проверить вкладки | Вкладки «ручная транзакция» **нет** (отключена в продукте) |

---

## ТК-P2. Без тарифа ONVI

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть раздел без фичи ONVI | Placeholder тарифа, полный CRUD недоступен |

---

## ТК-P3. Фильтры

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Поиск по коду/тексту | Список сужается |
| 2 | Тип: Все / Standalone / Campaign / Personal | Соответствующие записи |
| 3 | Статус: Активен / Неактивен / Все | Фильтрация по активности |

---

## ТК-P4. Создать промокод

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Нажать **Добавить** | Открывается drawer формы |
| 2 | Оставить обязательные поля пустыми → сохранить | Ошибки валидации |
| 3 | Заполнить код, тип скидки, значение, лимиты → сохранить | Успех, промокод в таблице |
| 4 | Для personal — выбрать пользователя (если поле есть) | Промокод привязан к пользователю |
| 5 | Отмена | Промокод не создан |

---

## ТК-P5. Редактировать промокод

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | В строке нажать **Редактировать** | Drawer с данными |
| 2 | Изменить значение → сохранить | В таблице новые данные |

---

## ТК-P6. Удалить промокод

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Нажать **Удалить** | Confirm (для campaign может быть предупреждение) |
| 2 | Подтвердить | Промокод исчез, toast успеха |
| 3 | Отменить в confirm | Промокод остаётся |
