# Пользователи (карты) и Заказы — сценарии для тестировщика

> В меню: **Пользователи** = карты (`/marketing/cards`), **Заказы** = транзакции программы.

---

## О странице

### Список карт — «Пользователи» (`/marketing/cards`)

| | |
|--|--|
| **Зачем** | Операционный реестр **карт лояльности**: кто пользуется мойками по программе, баланс, уровень, корпоративная ли карта. |
| **Что менеджерит** | Сущность **Card** (номер, unqNumber, клиент, тип virtual/physical, баланс, tier, corporate flag). Backend: `card-get-paginated`, `card-create` (через клиента), `card-import` (кнопка импорта). |
| **Кто пользуется** | Менеджер с `read`; add client / import — `update`. |
| **Связи** | Карточка карты; Клиенты; программа лояльности (обязательный контекст списка); импорт. |
| **Правила** | Без программ лояльности список карт по сути пуст. Программа выбирается / авто-выбирается первой. |

### Карточка карты (`/marketing/cards/card/:cardId`)

| | |
|--|--|
| **Зачем** | Детальная работа с одной картой и привязанным клиентом: правки, заказы, другие карты, активность, персональные промокоды, заметки менеджера. |
| **Что менеджерит** | Card + Client + bonus/ops feeds + notes + personal promocodes. Backend: `card-get-info`, `card-update-fields`, `card-operations-feed`, `client-get-activity`, userNote CRUD, promocode personal list. |
| **Кто пользуется** | `read` (просмотр); мутации — по правам update. |
| **Связи** | Список карт; профиль клиента; заказы (`from=orders`); управление промокодами. |
| **Правила** | Без клиента на карте — Empty «Клиент не привязан» на зависимых вкладках. Soft-смысл: карта может быть INACTIVE после delete клиента. |

### Заказы (`/marketing/marketing-transactions`)

| | |
|--|--|
| **Зачем** | Смотреть заказы мойки в рамках **программы лояльности** и при необходимости оформить **возврат** (refund). |
| **Что менеджерит** | Сущность **Order** (+ вложенные операции). Backend: `order-find-by-loyalty-program`, обновление статуса / platform order status (refund → REFUNDED); начисления кампаний связаны через order domain (`should-add-marketing-rewards` и др.). |
| **Кто пользуется** | Менеджер с `read` (список); refund — действие в UI при допустимых статусах. |
| **Связи** | Программа лояльности (обязательный select); карта/клиент заказа. |
| **Правила** | Без выбранной программы заказы **не запрашиваются**. Refund только для COMPLETED / PAYED / POS_PROCESSED. |

## ТК-U1. Открыть список карт

**Предусловия:** `read` LTYProgram; желательно есть хотя бы одна программа лояльности.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Маркетинг → **Пользователи** | Заголовок «Пользователи», таблица карт |
| 2 | Если есть программы | Автоматически выбрана первая программа, таблица заполняется |
| 3 | Если программ нет | Список карт пустой / не загружается — ожидаемо |

---

## ТК-U2. Фильтры карт

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Ввести **Уникальный номер карты** | Список сужается |
| 2 | Ввести **Номер карты** | Список сужается |
| 3 | Поиск клиента | Список по клиенту |
| 4 | Сменить **Программу лояльности** | Карты другой программы |

---

## ТК-U3. Импорт и добавление клиента с экрана карт

**Предусловия:** право update/manage.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Нажать **Импортирование карт** | Переход на страницу импорта |
| 2 | Нажать **Добавить** | Drawer создания клиента (как на Клиентах) |
| 3 | Без права update | Кнопок нет |

---

## ТК-U4. Открыть карточку карты

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Кликнуть по карте / номеру в таблице | `/marketing/cards/card/:cardId` |
| 2 | Проверить вкладки | **Обзор**, **Заказы**, **Карты**, **Активность**, **Промокоды**, **Заметки** |
| 3 | Нажать **Назад** | Возврат к списку (или к заказам, если `from=orders`) |

---

## ТК-U5. Карта с привязанным клиентом — вкладки

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Вкладка **Обзор** | Данные карты и клиента в сайдбаре/форме |
| 2 | Вкладка **Заказы** | Список заказов / пусто |
| 3 | Вкладка **Карты** | Другие карты этого клиента |
| 4 | Вкладка **Активность** | Лента активности |
| 5 | Сменить вкладку через UI | В URL появляется `?tab=…` |

---

## ТК-U6. Заметки на карте

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Вкладка **Заметки** → создать заметку | Заметка в списке |
| 2 | Изменить заметку | Текст обновился |
| 3 | Удалить заметку | Исчезла из списка |

---

## ТК-U7. Промокоды на карте

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Вкладка **Промокоды** | Список персональных промокодов клиента |
| 2 | Создать промокод (если кнопка есть) | Появляется в списке |
| 3 | Удалить | Исчезает после confirm |

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|

## ТК-Z1. Открыть Заказы

**Предусловия:** `read` LTYProgram.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Маркетинг → **Заказы** | Страница заказов |
| 2 | **Не выбирать** программу лояльности | Таблица заказов пустая / запрос не уходит — ожидаемо |
| 3 | Выбрать **программу лояльности** | Появляется список заказов |

---

## ТК-Z2. Фильтры заказов

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Ввести поиск | Список сужается (с задержкой ~0.5 с) |
| 2 | Выбрать POS (posId) | Только заказы точки |
| 3 | Фильтр статуса (Создан, Завершён, Оплачен, Возвращён…) | Только выбранный статус |
| 4 | Статус «Все» | Все заказы программы |

---

## ТК-Z3. Раскрыть заказ

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Раскрыть строку заказа (expand) | Видны операции: дата, тип, сумма, комментарий |

---

## ТК-Z4. Возврат (Refund)

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Найти заказ со статусом **Завершён / Оплачен / Обработан на POS** | Есть кнопка **Вернуть** |
| 2 | Нажать **Вернуть** → подтвердить | Toast «Заказ успешно возвращён», статус обновлён |
| 3 | Заказ со статусом **Создан** / **Возвращён** / **Отменён** | Кнопки **Вернуть** нет |
