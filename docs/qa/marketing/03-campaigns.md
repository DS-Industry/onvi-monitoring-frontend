# Маркетинговые кампании — сценарии для тестировщика

> Меню: **Маркетинг → Маркетинговые кампании**.

---

## О странице

### Список (`/marketing/campaigns`)

| | |
|--|--|
| **Зачем** | Видеть все акции организации: искать, фильтровать по статусу, создавать, удалять черновики, открывать профиль и статистику. |
| **Что менеджерит** | Реестр **Marketing campaign** (название, программа, статус, даты). Backend: find/list, `marketing-campaign-delete` (draft). |
| **Кто пользуется** | Менеджер с `read` (список) и `update` (create/delete draft). |
| **Связи** | Wizard create/edit, профиль, stats; привязка к **Loyalty program**. |
| **Правила** | Удаление из списка — **только draft**. Без `organizationId` список не грузится. |

### Wizard create/edit (`/marketing/campaign/create`)

| | |
|--|--|
| **Зачем** | Собрать акцию по шагам: базовые данные → тип исполнения → условия/награды → (опционально промо в приложении) → география (POS). |
| **Что менеджерит** | Campaign + **conditions** + **actions** + spend milestones + **mobile display** + POS. Backend: `marketing-campaign-create/update`, `condition-create/delete`, `action-create/update`, `create-spend-milestone-campaign`, `mobile-display-upsert`. |
| **Кто пользуется** | `update` LTYProgram; шаг Promotion — только owner программы Onvi (`VITE_ONVI_PROGRAM_ID`). |
| **Связи** | Список и профиль кампании; промокоды условий; программа лояльности. |
| **Правила** | Клик по Steps только в `mode=edit`. RewardValidityPeriod отключён. |

### Профиль (`/marketing/campaign/:id`)

| | |
|--|--|
| **Зачем** | Управлять жизненным циклом акции: запуск, пауза, отмена, реактивация; смотреть условия. |
| **Что менеджерит** | Статус кампании и просмотр conditions. Backend: `marketing-campaign-update` (ACTIVE), pause/cancel/reactivate handlers, status cron (`DRAFT→ACTIVE` / `ACTIVE→COMPLETED` по датам). |
| **Кто пользуется** | `update`. |
| **Связи** | Edit wizard, stats, список. |
| **Правила** | Явный UI на 404. Кнопки зависят от статуса. Delete — для draft. |

### Статистика (`/marketing/campaign/:id/stats`)

| | |
|--|--|
| **Зачем** | Оценить эффект акции: участники, usages, средний чек, тренды. |
| **Что менеджерит** | Только чтение аналитики. Backend: `get-marketing-campaign-analytics`. |
| **Кто пользуется** | `update` (как у профиля). |
| **Связи** | Профиль / список (`from=campaigns`). |
| **Правила** | Пустые тренды → «—»; ошибка → Alert. |

## ТК-M1. Открыть список кампаний

**Предусловия:** `read` LTYProgram.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Маркетинг → **Маркетинговые кампании** | Страница списка, заголовок раздела |
| 2 | Дождаться загрузки | Таблица или карточки кампаний (или «Нет данных») |

---

## ТК-M2. Поиск, фильтр, вид

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Ввести текст в поиск | Список сужается (с небольшой задержкой debounce) |
| 2 | Выбрать статус в фильтре | Только кампании этого статуса |
| 3 | Переключить вид **Таблица** / **Карточки** | Тот же набор данных в другом представлении |
| 4 | Листать пагинацию | Другая страница записей |

---

## ТК-M3. Создать кампанию (wizard)

**Предусловия:** `update` LTYProgram; есть программа лояльности.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Нажать **Создать** | Переход на `/marketing/campaign/create`, шаги wizard |
| 2 | Шаг **Основное**: заполнить название, даты, программу → сохранить/далее | Создаётся черновик, появляется id кампании |
| 3 | Шаг **Тип исполнения**: выбрать TRANSACTIONAL или BEHAVIORAL → далее | Шаг сохраняется |
| 4 | Шаг **Условия**: добавить условие → сохранить | Условие видно в списке условий |
| 5 | Удалить условие | Условие исчезает |
| 6 | Шаг **География**: выбрать POS/участников | Сохраняется привязка |
| 7 | Если программа = Onvi **и** вы owner программы | Появляется доп. шаг **Promotion** (промо в приложении) |
| 8 | Если другая программа / не owner | Шага Promotion **нет** |
| 9 | В режиме создания клик по шагам сверху | Переход по шагам ограничен (обычно только вперёд через UI шага) |

---

## ТК-M4. Редактировать кампанию через wizard

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Из списка открыть кампанию → перейти в редактирование (`mode=edit`) | URL с `marketingCampaignId`, `mode=edit`, `step` |
| 2 | Кликнуть по шагу в Steps | Переход на выбранный шаг |
| 3 | Изменить данные → сохранить | Данные обновлены на профиле/в списке |

---

## ТК-M5. Удалить черновик из списка

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | У кампании со статусом **черновик (DRAFT)** нажать **Удалить** | Confirm-диалог |
| 2 | Подтвердить удаление | Кампания исчезает из списка, сообщение об успехе |
| 3 | У активной кампании | Удаление недоступно или недопустимо (только draft) |

---

## ТК-M6. Профиль кампании — просмотр

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть кампанию из списка (клик по имени) | `/marketing/campaign/:id` — общая информация и условия |
| 2 | Открыть несуществующий id | Экран **не найдено (404)** |
| 3 | Нажать назад | Возврат к списку |

---

## ТК-M7. Lifecycle: запуск / пауза / отмена / реактивация

**Предусловия:** `update`; кампания готова к запуску.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | На профиле черновика нажать запуск (Play / аналог) | Статус становится **ACTIVE**, toast успеха |
| 2 | На активной нажать **Пауза** | Статус приостановлен, toast |
| 3 | Нажать **Реактивировать** | Снова активна |
| 4 | Нажать **Отменить** (Cancel) | Кампания отменена |
| 5 | Проверить, что кнопки зависят от статуса | Нерелевантные кнопки скрыты |

---

## ТК-M8. Статистика кампании

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Из списка или профиля открыть показатели / stats | `/marketing/campaign/:id/stats` |
| 2 | Выбрать период: неделя / месяц / год | KPI и график обновляются |
| 3 | Если тренд пустой | Вместо числа показывается «—» |
| 4 | При ошибке загрузки | Показан Alert с ошибкой |
| 5 | Вернуться назад (если заходили с `from=campaigns`) | Возврат в список кампаний |
