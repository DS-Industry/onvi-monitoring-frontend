# Warehouse QA checklist

## Доступ и навигация

- [ ] Авторизованный пользователь видит раздел Warehouse на тарифе `SPACE_AND_UP`.
- [ ] Пользователь без `read`/`manage` не получает доступ к рабочим экранам.
- [ ] Все маршруты открываются напрямую и сохраняют параметры URL.
- [ ] Кнопки создания и изменения скрыты без соответствующих прав.

## Склады и справочники

- [ ] Склады фильтруются по мойке и городу.
- [ ] Создание склада валидирует название, расположение, менеджера и мойку.
- [ ] Номенклатура фильтруется по поиску и категории.
- [ ] Создание и изменение номенклатуры сохраняют все обязательные и дополнительные поля.
- [ ] Артикул заблокирован в режиме редактирования.
- [ ] Группы отображаются деревом, вложенность сохраняется.
- [ ] Поставщики фильтруются по названию.
- [ ] Телефон поставщика проверяется в формате `+7XXXXXXXXXX`.

## Импорт

- [ ] Страница содержит инструкцию и ссылку на скачивание шаблона.
- [ ] Принимаются `.xlsx` и `.xls`.
- [ ] Выбранный файл можно удалить до отправки.
- [ ] Отправка без файла не выполняет запрос.
- [ ] После успешного импорта выполняется возврат к предыдущему экрану.

## Документы и остатки

- [ ] Список документов фильтруется по складу, городу и периоду.
- [ ] Поддерживаются все пять типов документов.
- [ ] Создание документа открывает форму с корректным `documentId`.
- [ ] Сохранение и отправка меняют статус документа.
- [ ] Отправленный документ можно вернуть только с правом изменения.
- [ ] Остатки отображают количество по каждому складу и корректную единицу измерения.
- [ ] Пустые результаты и ошибки API отображаются раздельно.

## Цены продажи

- [ ] Без выбранного склада добавление цены недоступно.
- [ ] Добавление цены не позволяет выбрать уже добавленную позицию.
- [ ] Отрицательная цена не сохраняется.
- [ ] Можно редактировать только одну строку одновременно.
- [ ] Удаление отключено без выбранных строк.

## Регрессия

- [ ] Пагинация и размеры страниц работают после каждого фильтра.
- [ ] Селектор колонок не теряет данные после обновления таблицы.
- [ ] Loading, empty state и error state отображаются без падения приложения.
- [ ] Основные сценарии проверены на desktop и mobile ширинах.
