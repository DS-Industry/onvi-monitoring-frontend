# QA: раздел Warehouse

Документация для тестировщиков и менеджеров продукта по складскому учёту: склады, номенклатура, группы, документы, остатки, поставщики и цены продажи.

## Маршруты

| Экран | URL | Компонент |
|---|---|---|
| Склады | `/warehouse/create` | `Warehouse` |
| Номенклатура | `/warehouse/inventory` | `InventoryCreation` |
| Импорт номенклатуры | `/warehouse/inventory/import` | `InventoryImport` |
| Группы номенклатуры | `/warehouse/inventoryGroups` | `InventoryGroups` |
| Документы | `/warehouse/documents` | `Documents` |
| Создание/редактирование документа | `/warehouse/documents/creation` | `DocumentsCreation` |
| Просмотр документа | `/warehouse/documents/view` | `DocumentView` |
| Остатки | `/warehouse/leftovers` | `OverheadCosts` |
| Поставщики | `/warehouse/suppliers` | `Suppliers` |
| Цены продажи | `/warehouse/salePrice` | `SalePrice` |

`/warehouse` — родительский маршрут с навигацией; рабочие экраны находятся в дочерних маршрутах.

## Общие предусловия

1. Пользователь авторизован и выбрана организация.
2. У пользователя есть `read` или `manage` на subject `Warehouse`.
3. Для создания и изменения данных дополнительно нужны права `create`/`update` или `manage`.
4. Для удаления номенклатуры и цен нужны права `delete` или `manage`.
5. Для сценариев с документами существуют склад, ответственное лицо и номенклатура.
6. Для сценариев с остатками подготовлены склады, категории и остатки с разными единицами измерения.
7. Раздел доступен для тарифа `SPACE_AND_UP`; фактическая доступность зависит от feature flags и прав пользователя.

## Бизнес-модель

- **Склад** — место хранения, связанное с мойкой и ответственным менеджером.
- **Номенклатура** — товар или материал с артикулом, категорией, поставщиком, единицей измерения, характеристиками и назначением.
- **Группа** — иерархическая категория номенклатуры; группа может быть вложена в другую группу.
- **Документ** — операция со складом: `RECEIPT`, `COMMISSIONING`, `WRITEOFF`, `MOVING` или `INVENTORY`.
- **Остаток** — количество номенклатуры в каждом складе, с общей суммой и единицей измерения.
- **Цена продажи** — цена номенклатуры для конкретного склада.
- **Поставщик** — контрагент номенклатуры с названием и контактным телефоном.

## Важные правила

- Фильтры и пагинация хранятся в URL; изменение фильтра сбрасывает страницу на первую.
- Артикул номенклатуры доступен для редактирования только при создании; при изменении он заблокирован.
- Для создания номенклатуры обязательны название, артикул, категория и единица измерения; поставщик и характеристики необязательны.
- Импорт принимает файлы `.xlsx` и `.xls`; шаблон скачивается из блока требований к файлу.
- Документ сначала создаётся с выбранным типом, затем заполняется и сохраняется или отправляется.
- Отправленный документ можно вернуть в сохранённое состояние только с правом `update`/`manage`.
- Цена не может быть отрицательной; добавление и удаление цены требуют выбранного склада.
- Пустые результаты показываются как empty state или пустая таблица; ошибка API отображается отдельно.
