# Warehouse: склады и остатки

## 1. Склады — `/warehouse/create`

### О странице

| Вопрос | Ответ |
|---|---|
| **Зачем** | Управлять местами хранения организации. |
| **Что менеджерит** | Список складов, фильтрацию по мойке и городу, создание склада. |
| **Кто пользуется** | Менеджеры склада и пользователи с доступом к `Warehouse`. |
| **Связи** | Мойка, город и ответственный менеджер. |
| **Правила** | При создании обязательны название, расположение, менеджер и мойка. |

### Тест-кейсы

#### ТК-WH-01 — список и создание склада

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `/warehouse/create` | Загружается таблица складов |
| 2 | Выбрать мойку или город | Таблица фильтруется, пагинация обновляется |
| 3 | Нажать Add | Открывается drawer с полями склада |
| 4 | Сохранить форму без обязательного поля | Показана валидация, запрос не отправляется |
| 5 | Заполнить все обязательные поля и сохранить | Склад создан, таблица обновлена |
| 6 | Открыть экран без `create`/`manage` | Кнопка Add недоступна |

## 2. Остатки — `/warehouse/leftovers`

### О странице

| Вопрос | Ответ |
|---|---|
| **Зачем** | Сравнивать количество номенклатуры по складам. |
| **Что менеджерит** | Фильтрацию по городу, складу и категории; просмотр количества и общей суммы. |
| **Кто пользуется** | Менеджеры склада, операционные руководители и аналитики. |
| **Связи** | Номенклатура, категории, склады и единицы измерения. |
| **Правила** | Для каждого склада создаётся отдельная колонка количества; данные зависят от выбранных фильтров. |

### Тест-кейсы

#### ТК-STK-01 — остатки и фильтры

**Предусловия:** одна номенклатура присутствует на нескольких складах.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `/warehouse/leftovers` | Таблица содержит номенклатуру, категорию, единицу, сумму и склады |
| 2 | Выбрать город | Показываются остатки складов выбранного города |
| 3 | Выбрать склад | В результатах остаются данные выбранного склада |
| 4 | Выбрать категорию | Показываются позиции выбранной категории; страница сбрасывается |
| 5 | Переключить страницу и размер | Пагинация соответствует фильтрам |
| 6 | Открыть селектор колонок | Колонки складов и базовые колонки можно скрывать/показывать |

#### ТК-STK-02 — пустые данные

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Выбрать комбинацию фильтров без остатков | Таблица пустая, ошибки нет |
| 2 | Смоделировать ошибку API | Показана ошибка загрузки, приложение остаётся работоспособным |
