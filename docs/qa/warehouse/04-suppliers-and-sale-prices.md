# Warehouse: поставщики и цены продажи

## 1. Поставщики — `/warehouse/suppliers`

### О странице

| Вопрос | Ответ |
|---|---|
| **Зачем** | Вести справочник поставщиков номенклатуры. |
| **Что менеджерит** | Поиск, пагинацию и создание поставщика. |
| **Кто пользуется** | Менеджеры склада и пользователи с доступом к `Warehouse`. |
| **Связи** | Поставщик выбирается при создании или изменении номенклатуры. |
| **Правила** | Обязательны название и телефон в формате `+7` и 10 цифр. |

### Тест-кейсы

#### ТК-SUP-01 — список, поиск и создание

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `/warehouse/suppliers` | Загружается таблица с номером, названием и контактом |
| 2 | Ввести название поставщика | Список фильтруется, страница сбрасывается |
| 3 | Нажать Reset | Поиск и пагинация возвращаются к значениям по умолчанию |
| 4 | Нажать Add и заполнить форму | Поставщик создан и список обновлён |
| 5 | Ввести некорректный телефон | Показана валидация, сохранение не выполняется |
| 6 | Открыть экран без `update`/`manage` | Кнопка Add недоступна |

## 2. Цены продажи — `/warehouse/salePrice`

### О странице

| Вопрос | Ответ |
|---|---|
| **Зачем** | Настраивать цену продажи номенклатуры на складе. |
| **Что менеджерит** | Выбор склада, добавление, изменение и удаление цен. |
| **Кто пользуется** | Менеджеры склада и пользователи с доступом к `Warehouse`. |
| **Связи** | Склад, номенклатура и остатки для продажи. |
| **Правила** | Без `warehouseId` добавление недоступно; одновременно редактируется одна строка; отрицательная цена не сохраняется. |

### Тест-кейсы

#### ТК-PRICE-01 — выбор склада и список

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `/warehouse/salePrice` | Отображаются фильтры города, мойки и склада |
| 2 | Выбрать склад | Загружаются цены выбранного склада |
| 3 | Сменить склад | Список заменяется данными нового склада |
| 4 | Открыть экран без выбранного склада | Кнопка Add disabled, запрос цен для склада не выполняется |

#### ТК-PRICE-02 — добавление, изменение и удаление

**Предусловия:** выбран склад, есть номенклатура без цены; у пользователя есть `update`/`manage`.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Нажать Add row | Открывается форма выбора номенклатуры и цены |
| 2 | Сохранить корректную цену | Новая строка появляется в таблице |
| 3 | Нажать Edit | Цена становится полем ввода |
| 4 | Ввести отрицательное значение | Кнопка Save недоступна |
| 5 | Ввести допустимое значение и сохранить | Цена обновлена |
| 6 | Выбрать строки и нажать Delete | Выбранные цены удалены после успешного ответа |
| 7 | Нажать Delete без выбранных строк | Действие недоступно |
