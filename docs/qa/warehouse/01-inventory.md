# Warehouse: номенклатура, группы и импорт

## 1. Номенклатура — `/warehouse/inventory`

### О странице

| Вопрос | Ответ |
|---|---|
| **Зачем** | Вести справочник товаров и материалов организации. |
| **Что менеджерит** | Поиск, фильтрацию по группе, создание, изменение и удаление номенклатуры. |
| **Кто пользуется** | Менеджеры склада и пользователи с доступом к `Warehouse`. |
| **Связи** | Категории, поставщики, единицы измерения и складские документы. |
| **Правила** | Артикул обязателен при создании и недоступен при редактировании; категория и единица измерения обязательны. |

### Тест-кейсы

#### ТК-INV-01 — список и фильтры

**Предусловия:** в организации есть номенклатура разных категорий.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `/warehouse/inventory` | Загружается таблица с артикулом, названием и категорией |
| 2 | Ввести поиск | В таблице остаются подходящие позиции; параметр `search` записан в URL |
| 3 | Выбрать категорию | Показываются позиции выбранной категории; страница сбрасывается на первую |
| 4 | Переключить размер страницы | Количество строк меняется, параметры `page` и `size` обновляются |
| 5 | Открыть селектор колонок | Можно скрывать и возвращать колонки таблицы |

#### ТК-INV-02 — создание номенклатуры

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Нажать Add | Открывается drawer создания |
| 2 | Заполнить название, артикул, категорию и единицу измерения | Поля принимают значения |
| 3 | Указать поставщика, описание, вес, габариты и назначение | Дополнительные данные отображаются в форме |
| 4 | Сохранить корректную форму | Номенклатура создана, таблица обновлена, выбранная категория отражена в URL |
| 5 | Оставить обязательное поле пустым | Показана валидация, запрос создания не выполняется |

#### ТК-INV-03 — изменение и удаление

**Предусловия:** у пользователя есть `update`/`manage`; для удаления — `delete`/`manage`.

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Нажать Edit у позиции | Drawer открывается с заполненными значениями |
| 2 | Проверить артикул | Артикул заблокирован |
| 3 | Изменить название или категорию и сохранить | Изменения сохранены, список обновлён |
| 4 | Нажать Delete | Позиция удалена из списка после успешного ответа |
| 5 | Открыть экран без прав изменения | Кнопки Add/Edit/Delete недоступны |

## 2. Группы номенклатуры — `/warehouse/inventoryGroups`

### О странице

| Вопрос | Ответ |
|---|---|
| **Зачем** | Организовать номенклатуру в иерархию категорий. |
| **Что менеджерит** | Создание корневых и вложенных групп, редактирование названия и описания. |
| **Кто пользуется** | Менеджеры склада и пользователи с доступом к `Warehouse`. |
| **Связи** | Номенклатура использует группу как категорию. |
| **Правила** | Дочерняя группа выбирает родительскую; список отображается в виде раскрываемого дерева. |

### Тест-кейсы

#### ТК-GRP-01 — дерево групп

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть экран | Загружается дерево категорий |
| 2 | Раскрыть родительскую группу | Видны вложенные группы |
| 3 | Открыть экран без групп | Показан empty state |
| 4 | Смоделировать ошибку API | Показана ошибка, приложение не падает |

#### ТК-GRP-02 — создание и редактирование

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Нажать Add | Открывается drawer создания |
| 2 | Заполнить название и описание, выбрать родителя | Новая группа создаётся в выбранной ветке |
| 3 | Нажать Edit у группы | Поля названия и описания становятся редактируемыми |
| 4 | Сохранить изменения | Значения обновлены в дереве |
| 5 | Отменить редактирование | Изменения не сохраняются |
