# Сотрудники — сценарии для тестировщика

> Меню: **HR → Сотрудники**.  
> Формат ТК: **Предусловия → Шаги → Ожидаемый результат**.

Общие предусловия раздела: план **SPACE** / **BUSINESS** / **CUSTOM**, организация, права `Hr`.

Порядок выплат и ставки: [00-how-it-works.md](./00-how-it-works.md).

---

## О странице

### Список сотрудников (`/hr/employees`)

| | |
|--|--|
| **Зачем** | Вести список работников АМС: искать, заводить карточку, открывать профиль. |
| **Что менеджерит** | Сущность **HrWorker** (ФИО, должность, город, организация, оклады на карточке). Backend: `worker-create`, `worker-find-methods`. |
| **Кто пользуется** | HR организации с `read` на `Hr`. Кнопка добавления — `update` или `manage`. |
| **Связи** | Профиль сотрудника; справочник **Должности**; точки АМС задаются уже в профиле. |
| **Правила** | Список без `status` отдаёт только **`WORKS`**. Уволенные в этой таблице не видны. Работник — не пользователь программы. |

### Drawer «Добавить сотрудника»

| | |
|--|--|
| **Зачем** | Завести работника в базу, не открывая профиль заранее. |
| **Что менеджерит** | Create **HrWorker** (multipart, опционально фото). После успеха переход в профиль на вкладку точек. |
| **Кто пользуется** | HR с `update` / `manage`. |
| **Связи** | Нужна хотя бы одна должность. Точки АМС — следующим шагом в профиле. |
| **Правила** | Обязательны ФИО, должность, город, организация. Поля «Месячный оклад» и «Дневной оклад» есть в форме; месячный оклад **не правило продукта**. Текст `hr.if` про процент с автомобиля в UI есть; **правилом продукта не является** — не проверять как начисление. |

## ТК-E1. Открыть список сотрудников

**Предусловия:** право `read` на `Hr`.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | В боковом меню открыть **HR** | Раскрывается подменю |
| 2 | Нажать **Сотрудники** | Открывается `/hr/employees`, заголовок «Сотрудники» |
| 3 | Дождаться загрузки | Таблица (или пустая). Колонки: ФИО Сотрудника (ссылка), город, организация, должность |

---

## ТК-E2. Отфильтровать сотрудников

**Предусловия:** в списке есть сотрудники с разными городом / должностью / ФИО.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть Сотрудники | Список загружен |
| 2 | В фильтре выбрать **Город** | Таблица ограничена городом; в URL есть `city` |
| 3 | Выбрать **Должность** | Только выбранная должность (`hrPositionId`) |
| 4 | Выбрать **Организация** | Список по организации |
| 5 | Ввести текст в **ФИО** | Список сужается по имени (`name`) |
| 6 | Сбросить фильтры | Снова полный список действующих |

---

## ТК-E3. Создать сотрудника

**Предусловия:** есть должность; право `update` или `manage` на `Hr`.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Нажать **Добавить сотрудника** | Справа drawer с заголовком «Добавить сотрудника» |
| 2 | Оставить ФИО и должность пустыми → сохранить | Ошибки валидации (обязательны ФИО, должность, город, организация) |
| 3 | Заполнить **ФИО**, **Выберите должность**, город, организацию | Поля приняты |
| 4 | По желанию: дата приема, фото, дневной оклад, паспортный блок | Поля заполняются; месячный оклад можно заполнить, на расчёт смен это не влияет |
| 5 | Нажать **Добавить сотрудника** | Успех, drawer закрывается, переход на `/hr/employees/profile?workerId=…&tab=poses` |
| 6 | Если точки не выбраны | Предупреждение «Для сотрудника еще не выбраны точки продаж. Пожалуйста, выберите точки.» |

---

## ТК-E4. Перейти в профиль

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | В таблице кликнуть по **ФИО** | Переход на `/hr/employees/profile?workerId=…` |
| 2 | Проверить заголовок | Имя сотрудника (не заглушка маршрута «Сидоров Егор Андреевич») |

Дальше — [03-employee-profile.md](./03-employee-profile.md).

## ТК-E5. Нет должности в списке

**Предусловия:** для сценария создания нет нужной должности.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть drawer добавления | В подсказке: должность можно добавить в **HR/Должности** (`hr.ifThe`) |
| 2 | Открыть **Должности**, создать должность | См. ТК-J2 |
| 3 | Вернуться к добавлению сотрудника | Новая должность есть в «Выберите должность» |

Без должности create сотрудника не проходит.
