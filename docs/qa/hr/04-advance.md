# Аванс — сценарии для тестировщика

> Меню: **HR → Аванс сотрудников**.  
> Формат ТК: **Предусловия → Шаги → Ожидаемый результат**.

Общие предусловия: план **SPACE** / **BUSINESS** / **CUSTOM**, права `Hr`.

**Табель** (раздел **Управление → Табель учета рабочего времени**) — только предусловие: у сотрудника есть отправленные рабочие смены за месяц. Весь финансы здесь не описываем.

---

## О странице

### Список авансов (`/hr/employee/advance`)

| | |
|--|--|
| **Зачем** | Видеть уже сформированные авансы, поправить сумму/дату выдачи, удалить ошибочный отчёт. |
| **Что менеджерит** | **HrPayment** с типом `PREPAYMENT`. Backend: отчёт, update, delete. |
| **Кто пользуется** | Управляющий / HR с `read`. Создать — `create` / `manage`. Правка и удаление — `delete` / `manage`. |
| **Связи** | Сотрудники, смены табеля, затем **Расчет ЗП** (вычитает этот аванс). |
| **Правила** | **Бизнес:** на сотрудника в месяц — один аванс. **Код:** calculate прячет уже посчитанных; повторный create через API возможен, unique нет; после delete снова calculate. |

### Создание (`/hr/employee/advance/creation`)

| | |
|--|--|
| **Зачем** | Собрать аванс по сменам выбранного месяца и сохранить выплаты. |
| **Что менеджерит** | Calculate + create PREPAYMENT (`prize`/`fine` = 0). |
| **Кто пользуется** | Управляющий с `create` / `manage`. |
| **Связи** | Нужны должность, привязка к АМС, **отправленные** смены. |
| **Правила** | Нет смен → пустой список, не ошибка расчёта. Аванс раньше ЗП по смыслу, но ЗП можно сделать и без него. |

## ТК-A1. Открыть список авансов

**Предусловия:** право `read` на `Hr`.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Меню **HR → Аванс сотрудников** | `/hr/employee/advance`, заголовок «Аванс сотрудников» |
| 2 | Дождаться загрузки | Таблица или пусто. Колонки ориентир: ФИО, месяц расчёта, дата выдачи, посменное начисление, число смен, выплачено |

---

## ТК-A2. Создать аванс (есть смены)

**Предусловия:** сотрудник WORKS, должность, точки АМС, в табеле за месяц есть смены `WORKING` + отправленные. Право `create` / `manage`.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Нажать **Создать** | `/hr/employee/advance/creation` |
| 2 | Выбрать организацию и **Расчётный месяц**, при необходимости должность | Поля формы |
| 3 | Нажать **Сформировать** | Таблица строк calculate: ФИО, месяц, посменное начисление, смены, выплата |
| 4 | Проставить дату выдачи, при необходимости поправить сумму | Сумма > 0 |
| 5 | Сохранить | Успех, запись в списке авансов |

---

## ТК-A3. Пустой период (нет смен)

**Предусловия:** месяц без отправленных рабочих смен у доступных сотрудников.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Создание аванса → месяц без смен → **Сформировать** | Пустая таблица. Это **не** ошибка расчёта (сервер `[]`) |
| 2 | Сохранить пустой набор | Новых выплат нет |

---

## ТК-A4. Второй аванс за тот же месяц

**Предусловия:** по ТК-A2 аванс уже сохранён.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Снова открыть создание, тот же месяц → **Сформировать** | **Бизнес:** второго аванса быть не должно. **Код (UI):** сотрудника в calculate нет (уже есть выплата за месяц) |
| 2 | Повторный POST create через API с тем же работником и месяцем | **Бизнес:** отказ. **Код:** unique нет, проверка «аванс уже есть» выключена — вторая запись возможна |
| 3 | Смотреть список | Если шаг 2 сделали — в списке может быть больше одной строки на человека и месяц |

---

## ТК-A5. Редактировать аванс

**Предусловия:** есть строка аванса; `delete` или `manage` на `Hr`.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | В списке **Редактировать** | Редактируются сумма и время выплаты |
| 2 | Изменить сумму → **Сохранить** | Новая сумма в таблице |

---

## ТК-A6. Удалить аванс

**Предусловия:** как ТК-A5.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Отметить строки → удалить → подтвердить | Записи нет в списке |
| 2 | Отмена в диалоге | Запись на месте |

---

## ТК-A7. После удаления снова calculate

**Предусловия:** аванс удалён по ТК-A6; смены за месяц на месте.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Создание → тот же месяц → **Сформировать** | Сотрудник снова в списке calculate |
| 2 | Сохранить | Новый аванс создаётся |
