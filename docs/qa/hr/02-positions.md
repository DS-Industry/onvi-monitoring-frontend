# Должности — сценарии для тестировщика

> Меню: **HR → Должности**.  
> Формат ТК: **Предусловия → Шаги → Ожидаемый результат**.

Общие предусловия: план **SPACE** / **BUSINESS** / **CUSTOM**, организация, права `Hr`.

---

## О странице

### Список должностей (`/hr/positions`)

| | |
|--|--|
| **Зачем** | Справочник должностей организации: без должности нельзя завести сотрудника и задать ставки смены на АМС. |
| **Что менеджерит** | Сущность **HrPosition** (название, описание). Backend: `position-create`, `position-update` (только описание), `position-find-methods`. |
| **Кто пользуется** | HR с `read`. Создание и правка — `update` / `manage`. |
| **Связи** | Сотрудники (выбор должности); профиль АМС → **Стоимость смен** (ставки день/ночь по должности). |
| **Правила** | Имя при create обязательно. Через API **имя изменить нельзя** (в update только описание). Удаления должности в API нет. В сайдбаре у пункта `isHr: true` — визуальный разделитель, не отдельное право. |

---

## ТК-J1. Открыть список должностей

**Предусловия:** право `read` на `Hr`.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | В меню **HR** нажать **Должности** | Открывается `/hr/positions`, заголовок «Должности» |
| 2 | Дождаться загрузки | Таблица: колонки **Должность**, **Описание** (или пусто / «Пока не создана ни одна должность») |

---

## ТК-J2. Создать должность

**Предусловия:** право `update` или `manage` на `Hr`.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Нажать **Новая должность** | Справа drawer «Создать должность» |
| 2 | Оставить название пустым → сохранить | Ошибка: название обязательно |
| 3 | Не выбрать организацию (если поле видно) → сохранить | Ошибка организации |
| 4 | Ввести **Название**, организацию, по желанию описание → **Создать должность** | Drawer закрывается, должность есть в таблице |
| 5 | Открыть создание сотрудника | Новая должность в «Выберите должность» |

---

## ТК-J3. Редактировать должность

**Предусловия:** есть должность; право `update` / `manage`.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | В строке нажать иконку редактирования | Строка в режиме правки |
| 2 | Изменить **Описание** → подтвердить | Описание сохранилось после обновления списка |
| 3 | Попытаться изменить **название** в UI, если поля нет | Ожидаемо: на экране правят описание; смены имени через этот API нет |
| 4 | Без права `update` | Кнопки «Новая должность» и карандаша нет |
