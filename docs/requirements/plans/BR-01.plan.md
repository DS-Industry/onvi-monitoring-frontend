# BR-01 — implementation plan

> Generated by `/kickoff` after human approval. Execute with `/execute BR-01`.

## Goal

Технический персонал текущей организации включает интеграцию миниПК на просмотре филиала и смотрит список и карточку связки «объект — миниПК — Казначей» на новой странице «Работа с ФН».

## Grade

L

- FSD: `docs/requirements/FSD.md` (BR-01)
- Design: `DESIGN.md` (S2, S3, S4), `docs/design/S2-fiscal-object-toggle.png`, `docs/design/S3-fiscal-list.png`, `docs/design/S4-fiscal-card.png`
- API: `onvi_monitoring_backend` `PosFiscalController` (`pos/fiscal`)

## Decisions

- Клиент: `GET /pos/fiscal`, `GET /pos/fiscal/:posId`, `PATCH /pos/fiscal/:posId` с телом `{ enabled }`.
- Состояние в строке списка: строка `statusLine` и время `receivedAt`. Дополнительно, если значение есть: память ФН переполнена (`fnMemoryOverflow`), ресурс ФН исчерпан (`fnResourceExhausted`), требуется замена ФН (`fnReplacementRequired`), число неотправленных в ОФД (`ofdUnsentDocumentsCount` > 0).
- Пустая колонка «Предупреждение» показывает «—».
- Переключатель «Интеграция миниПК» на существующей вкладке финансов филиала, под блоком ФинТабло. Подпись вкладки «ФинТабло» не меняется.
- Страница информации — новый пункт меню «Оборудование» → «Работа с ФН». Список: `/equipment/fn`. Карточка: `/equipment/fn/:posId`.
- Пагинация списка как у техзадач: `page` и `size` в query, таблица Ant Design, `DEFAULT_PAGE_SIZE` из `@/utils/constants`.
- Фильтр предупреждения: «Все» (`warning=all`) и «С предупреждением» (`warning=warning`).
- Оплата в карточке: `PAPER` и `COIN` → «Наличные», `POS` → «Безналичные». Ответ миниПК уже приходит этими подписями.
- Поиск, регион и страна с макета S3 в экран не входят.
- Период — существующий `PeriodToggle` (`src/pages/Pos/Overview/components/PeriodToggle.tsx`). При открытии выбран текущий день.

## Out of scope

- Контроль в период без зачислений.
- Проверка доставки чека оператору ОФД или в налоговую.
- Уведомления и действие «создать заявку».
- Поиск, регион и страна на списке.
- Переименование вкладки «ФинТабло».
- Изменение схемы базы и протокола оборудования.

## Risks

- Родительский маршрут `/equipment` сейчас открывается по правам Incident/TechTask и тарифу `BUSINESS_AND_UP`. Без read Pos на родителе пользователь только с правом Pos пункт не увидит.
- API списка и карточки требует подписочную фичу `Pos`. Экран должен показывать тот же отказ доступа, что и другие экраны с этой фичей.
- Предупреждения приходят готовыми строками «Расходится время» и «Расходятся суммы». Фронт их не пересчитывает.
